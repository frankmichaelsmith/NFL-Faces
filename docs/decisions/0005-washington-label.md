# 0005 — Washington's wheel label

**Date:** 2026-09-09 · **Decided by:** Frank

The team wheel reads **"Washington"** for every season. No season-accurate aliases (Redskins 2000–19, Football Team 2020–21, Commanders 2022→). Since Washington is the only franchise whose nickname changed since 2000, the alias feature proposed in the design review is dropped entirely; `teams.csv` has one label per franchise.
